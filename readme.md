# Windows XP 安装程序模拟器（Web 版）

一个完全运行在浏览器中的 Windows XP 安装过程模拟器。它使用 IndexedDB 作为虚拟文件系统，真实地“写入”系统文件，并支持刷新后保留状态。项目包含 BIOS 自检、文本安装、图形界面安装、OOBE 欢迎界面以及一个可交互的 XP 风格桌面。

> **注意：** 本项目仅用于怀旧、娱乐和教育目的。它**不是**微软的官方产品，也不包含任何微软的专有代码或资源。

---

## 功能特性

- **完整的安装流程**：BIOS → 文本模式安装 → 图形界面安装 → OOBE → 桌面
- **真实的文件持久化**：所有系统文件写入浏览器 IndexedDB，刷新页面后依然存在
- **可交互的 XP 桌面**：
  - 我的电脑、记事本、Internet Explorer、回收站
  - 开始菜单、任务栏、时钟
  - 窗口拖动、最小化、关闭
- **记事本**：可编辑并保存文件到“我的文档”
- **Internet Explorer**：通过 iframe 加载真实网页（受目标网站 X-Frame-Options 限制）
- **安装损坏检测与修复**：关键文件缺失时可自动修复或全新安装
- **恢复出厂设置**：清空所有模拟文件并重新安装

---

## 如何运行

1. 将 `index.html` 保存到本地。
2. 使用现代浏览器（Chrome、Edge、Firefox、Safari）打开。
3. 首次打开会从 BIOS 开始完整安装流程。
4. 安装完成后即可进入 XP 桌面。

> **建议**：由于浏览器对 `file://` 协议下的 IndexedDB 支持不一致，推荐使用本地 HTTP 服务器运行，例如：
> ```bash
> npx serve .
> # 或
> python -m http.server
```

然后访问 http://localhost:端口号。
